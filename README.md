# Stars Without Number — интерактивная звёздная карта

Сайт-справочник для НРИ-кампании по **Stars Without Number**: большая 3D-карта
сектора, по которой можно летать от масштаба галактики до поверхности планеты,
кликать по системам и планетам и читать их карточки.

Стек: **Vite + Three.js (vanilla) + GSAP**.

---

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173  (открыто и с телефона в той же сети)
npm run build      # прод-сборка в dist/
npm run preview
```

> Ассеты лежат в `public/` в корне репозитория. Vite настроен отдавать их в корень
> сайта (`publicDir: '../public'` в `vite.config.js`), поэтому в коде пути пишутся
> **без** префикса `public/` и через прямой слеш: `'/planets/textures/Mars.jpg'`.
> Прежние `'public\\planets\\textures\\Pluto.jpg'` в браузере не работали никогда
> (обратный слеш не является разделителем URL).

## Быстрый старт (управление)

* **ЛКМ-драг** — орбита, **ПКМ-драг** — панорама, **колесо** — зум.
* **W A S D** — полёт, **Q/E** — вниз/вверх, **Shift** — ускоритель, **Space** — точный режим.
* Движение (клавиши/колесо) при открытой карточке закрывает её и возвращает управление.
* **0…9 / [ / ]** или слайдер внизу — ручной масштаб скорости (×0.1…×10).
* **Клик по звезде/планете** — подлёт и карточка; **Esc** — вернуться.
* На телефоне: 1 палец — орбита, пинч — зум, джойстик слева — стрейф,
  кнопки справа — тяга и высота.

Полная раскладка и обоснование каждого решения — в [`src/map/CAMERA.md`](src/map/CAMERA.md).

## Твои системы на карте

Карта-основа — `public/nebulae/models/nebula_mapa.glb` (1000 узлов + связи).
Чтобы основать систему:

1. Кликни по узлу на карте — в карточке будет его номер («узел #512»),
   либо смотри `SWN.chart.dumpNodes()` в консоли.
2. Добавь запись в `src/map/systems.data.js`:
   `{ node: 512, name: '…', star: {…}, planets: [ … ] }`.
3. Перезагрузи страницу. Остальные узлы останутся «необследованными» —
   это и иллюзия живого сектора, и заготовки под будущие записи.

Фон неба — твоя панорама `billions_stars_skybox_hdri_panorama.glb`;
«множество звёзд» — перекрашенное облако `need_some_space.glb`.

## Из консоли

```js
SWN.chart.dumpNodes()                       // номера узлов nebula_mapa.glb
SWN.rig.flyTo({ position: SWN.rig.toRender(SWN.chart.named()[0].pos), dist: 2000 })
SWN.rig.setSpeedMultiplier(6)
SWN.map.systems.length          // 2500
SWN.rig.telemetry()             // fps, dist, speed, near/far, rebases…
```
