# 🎨 Медиа-ресурсы и материалы кампании (Assets)

В этой папке и её подпапках хранятся все графические и 3D-материалы для вашего сайта-справочника по **Stars Without Number**.

## 📂 Структура подпапок:
1. **`characters/`** — Портреты игроков (PC), NPC и фракций.
2. **`planets/`** — 3D-модели планет (`.glb` / `.gltf`) и текстуры поверхности/атмосферы.
3. **`stars/`** — Текстуры солнц, спрайты короны, модели пульсаров и квазаров.
4. **`nebulae/`** — Скайбоксы, Hubble-спрайты и объёмные модели туманностей.
5. **`history/`** — Баннеры и обложки для исторических эпох и сессий кампании.
6. **`rules/`** — Иллюстрации для классов, рас и правил SWN.
7. **`sheets/`** — Аватары для интерактивных листов персонажей.
8. **`emblems/`** — Логотипы, иконки и эмблемы кампании.

В `stars/README.md` и `nebulae/README.md` лежит подборка проверенных бесплатных источников (NASA/Chandra, Solar System Scope, Sketchfab CC-BY).

### Git LFS

Крупные модели (`.glb` `.stl` `.obj` `.fbx` `.bin`) идут через Git LFS. Паттерны уже прописаны в корневом `.gitattributes`.

Перед коммитом моделей:

```powershell
git lfs install
git lfs track
```

Не запускайте `git lfs migrate import --everything` — это переписывает всю историю, включая `main`.

На бесплатном GitHub LFS лимит около **1 ГБ**. STL от NASA часто по 10–40 МБ. Перед заливкой сожмите в `.glb` в Blender (Export → glTF, Compression) и не коммитьте сырые 8K/16K, если хватает 2K/4K.

### Что карта реально грузит

LOD в `ThreeGalaxyScene`:

| Зум | Что на экране | Что грузится |
|---|---|---|
| Галактика | скайбокс 2K, регионы, яркие точки, 2–3 спрайта туманностей | JPG/PNG, никаких GLB |
| Приближение | границы тают, системы как маленькие солнца | текстура солнца |
| Система | орбиты + планеты средним качеством | JPG на сфере, 24–28 сегментов |
| Планета | одна выбранная планета | один GLB < 5 МБ или hi-res сфера |

Не вешайте на карту: `various_planets.glb` (35 МБ), `uranus scene.bin` (82 МБ), `borite.glb` (28 МБ), `nebula_skybox_16k.glb`, FBX, USDZ, particle scene.

### Сцена + `.bin` + папка текстур

Так экспортирует Sketchfab. Это **один набор**, пути внутри `.gltf` ждут соседнюю папку `textures/`. Если разнести `models/` и `textures/`, модель приедет без кожи.

Как чинить в Blender:

1. Импортировать `.gltf` из **оригинальной** папки Sketchfab, пока пути целые.
2. File → Export → glTF 2.0 → формат **glTF Binary (.glb)**, включить Compression.
3. Один файл класть в `models/`. Текстуры внутри, отдельные PNG больше не нужны.

### Несколько планет в одном файле

`various_planets.glb`, `exoplanets.glb`, `sci-fi planets scene` — это пачки. Разделить:

1. Blender → Import GLB/GLTF.
2. В Outliner выбрать один меш планеты.
3. Select → Select Linked, потом File → Export → glTF, галка **Limit to Selected Objects**.
4. Повторить для каждой планеты. Имена: `avalon-prime.glb`, `sparta-mars.glb`.

Сервиса «склеить всё и вставить на сайт» нет. Каталог — `src/lib/spaceAssets.ts`: там написано, какой файл к какой системе и на каком LOD он живёт.

### 📌 Как обращаться к файлам из кода или через интерфейс:
Любой файл, добавленный в эти папки, доступен в приложении по пути, начинающемуся с `/assets/...`

**Пример:**  
Если вы добавили файл `public/assets/characters/vane.webp`, то в интерфейсе создания или редактирования персонажа в поле «URL портрета» введите:  
` /assets/characters/vane.webp`
