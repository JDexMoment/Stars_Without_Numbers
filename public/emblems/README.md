# 🛡️ Эмблемы и символика кампании (`/assets/emblems/`)

Сюда кладите логотипы фракций, символы орденов, гербы и эмблемы сектора.

- **Рекомендуемые форматы**: `.png` (с прозрачным фоном) или `.svg`
- **Рекомендуемое разрешение**: `512x512 px`
- **Как использовать**:
  Файлы подходят для иконок фракций на карте и брендинга в навигационном меню.
