# 📜 Баннеры и иллюстрации летописи (`/assets/history/`)

Сюда кладите обложки для исторических эпох, сюжетных арок и прошедших игровых сессий.

- **Рекомендуемые форматы**: `.jpg`, `.webp`, `.png`
- **Рекомендуемое разрешение**: `1200x600 px` (горизонтальный баннер 2:1 или 16:9)
- **Как использовать в приложении**:
  В модальном окне вставки изображения в летопись сессий или в заметках укажите путь:
  `/assets/history/имя_файла.jpg`
