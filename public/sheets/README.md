# 🛡️ Аватары и иконки листов персонажей (`/assets/sheets/`)

Сюда кладите миниатюры и аватары для интерактивных листов персонажей, создаваемых в личном кабинете.

- **Рекомендуемые форматы**: `.webp`, `.png`, `.jpg`
- **Рекомендуемое разрешение**: `400x400 px` (квадрат)
- **Как использовать в приложении**:
  При работе в «Конструкторе Персонажа SWN» вставьте путь к аватару:
  `/assets/sheets/имя_файла.jpg`
