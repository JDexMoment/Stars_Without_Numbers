# 👥 Портреты персонажей и NPC (`/assets/characters/`)

Сюда кладите изображения для карточек персонажей игроков (PC), NPC и лидеров фракций.

- **Рекомендуемые форматы**: `.webp`, `.jpg`, `.png`
- **Рекомендуемое разрешение**: `600x800 px` (вертикальный портрет 3:4 или квадрат 1:1)
- **Как использовать в приложении**:
  При создании или редактировании персонажа в поле «URL портрета / арта» введите:
  `/assets/characters/имя_файла.jpg` (например: `/assets/characters/captain-vane.webp`)
