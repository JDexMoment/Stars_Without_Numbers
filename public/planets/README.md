# 🪐 3D-модели и текстуры планет (`/assets/planets/`)

Сюда кладите материалы для отображения космических тел на 3D-карте галактики.

- **Форматы для 3D-моделей**: `.glb`, `.gltf` (готовые оптимизированные 3D-модели планет или космических станций)
- **Форматы для текстур**: `.jpg`, `.png` (карты высот, diffuse/color текстуры, облака, кольца — рекомендуемое разрешение `2048x1024` для эквиректанглярной проекции)
- **Как использовать**:
  Эти ресурсы можно подключать для индивидуальной кастомизации планет в 3D-сцене Three.js (в конфигурации звёздных систем `src/lib/initialData.ts`).

Солнце системы, пульсары и квазары кладите не сюда, а в `/assets/stars/`. Туманности и скайбокс галактики — в `/assets/nebulae/`.
