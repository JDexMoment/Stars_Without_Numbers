# 📖 Иллюстрации правил, рас и классов (`/assets/rules/`)

Сюда кладите арт для оформления страниц со шпаргалкой, описаниями 4 классов SWN и расами сектора.

- **Рекомендуемые форматы**: `.webp`, `.jpg`, `.png`
- **Рекомендуемое разрешение**: `800x500 px` или `600x600 px`
- **Как использовать**:
  Файлы из этой папки используются для иллюстрации лора рас, происхождения и игровых механик.
