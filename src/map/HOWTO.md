# HOWTO — как добавлять и менять системы и планеты

Всё редактируется в **одном файле**: `src/map/systems.data.js`.
Перезапускать ничего не нужно — `npm run dev` подхватывает изменения на лету.

---

## Быстрый старт (3 шага)

1. **Найди узел.** Кликни по тусклой точке на карте («необследованная система») —
   в карточке будет её номер (`узел #512`) и **готовый шаблон записи**, который
   можно скопировать целиком. Альтернатива: в консоли браузера (F12) —
   `SWN.chart.dumpNodes(1000)` — таблица всех узлов с координатами.
2. **Вставь запись** в массив `SYSTEMS` в `src/map/systems.data.js`.
3. **Сохрани файл.** Карта обновится сама.

Минимальная рабочая запись — две строки:

```js
{ node: 512, name: 'Моя система' }
```

Всё остальное (звезда, орбиты, скорости) движок подставит сам.

## Система: поля

| Поле      | Что делает                                        | Пример |
|-----------|---------------------------------------------------|--------|
| `node`    | номер узла карты; либо `'auto:center'` / `'auto:edge'` | `512` |
| `at`      | координаты вместо узла (редко нужно)              | `[12000, 0, -8000]` |
| `name`    | имя системы (**обязательно**)                     | `'Гелиос'` |
| `role`    | строка под именем в карточке                      | `'столица сектора'` |
| `pop`     | население (текст)                                 | `'4 200 млн'` |
| `tech`    | техуровень (текст)                                | `'уровень 4'` |
| `tags`    | метки-чипы в карточке                             | `['верфь', 'патруль']` |
| `star`    | звезда — см. ниже                                 | `'sun'` |
| `planets` | массив планет — см. ниже                          | |

## Звезда: короткие формы

`star` можно написать **строкой**:

| Написал            | Получил |
|--------------------|---------|
| `'sun'`            | модель `/stars/models/sun.glb` |
| `'blackhole'`      | модель `/stars/models/blackhole.glb` |
| `'dyson'`          | модель `/stars/models/dyson_sphere.glb` |
| `'startut'`        | модель `/stars/models/startut.glb` |
| `'ssimpossible-sun'` | модель `/stars/models/ssimpossible-sun.glb` |
| `'красный'`, `'голубой'`, `'жёлтый'`, `'оранжевый'`, `'золотой'`, `'зелёный'`, `'фиолетовый'`, `'белый'`, `'синий'` | обычная звезда-сфера этого цвета |
| `'#ffcc66'` или `0xffcc66` | звезда-сфера этого цвета |
| `'моя-звезда.glb'` | модель `/stars/models/моя-звезда.glb` |

Полная форма (если нужен и цвет, и размер):

```js
star: { model: '/stars/models/sun.glb', color: 0xffe08a, radius: 3.2 }
```

## Планета: поля

| Поле      | Что делает                                            | Пример |
|-----------|-------------------------------------------------------|--------|
| `name`    | имя                                                    | `'Венера'` |
| `tag`     | римский номер в карточке                               | `'II'` |
| `kind`    | описание класса                                        | `'терранская'` |
| `size`    | радиус в юнитах (синоним `radius`)                     | `1.4` |
| `texture` | **короткое имя**: `'Mars'` → `/planets/textures/Mars.jpg` | `'Europa'` |
| `color`   | однотонная планета: слово / `'#hex'` / `0xhex`         | `'красный'` |
| `model`   | своя .glb-модель вместо сферы                          | `'/stars/models/blackhole.glb'` |
| `orbit`   | радиус орбиты; **не укажешь — расставим сами** (30, 55, 80…) | `40` |
| `speed`   | скорость орбиты; по умолчанию `0.002`                  | `0.004` |
| `ring`    | `true` — планета с кольцами                            | `true` |
| `offset`  | `[x,y,z]` — статичный объект вместо орбиты             | `[-10, -5, -10]` |
| `lockRotation` | не давать вращать объект мышью                    | `true` |
| `focusCore`    | камерой целиться в меш с `'core'` в имени         | `true` |

Что-то одно из `texture` / `color` / `model`. Доступные текстуры:
**Europa, Mars, Neptune, Pluto, Saturn, Venus** (лежат в `public/planets/textures/`).

## Ориентиры масштаба

Реальные размеры в сцене: звезда ~3 юнита, планеты 0.5–3, орбиты 20–120.
Камера подлетает к системе на ~150–900 юнитов — держись этих чисел, и система
будет выглядеть правильно. Скорости: `0.0005` — лениво, `0.002` — нормально,
`0.004` — быстро (движок дополнительно замедляет всё в ~3 раза, чтобы вращение
было спокойным — это константа `ORBIT_SLOW` в `chartMap.js`).

## Добавить систему без перезагрузки (консоль)

```js
SWN.chart.addSystem({
  node: 512,
  name: 'Тест',
  star: 'sun',
  planets: [{ name: 'Планета', texture: 'Mars', size: 1.4 }],
})
```

Удобно подбирать вид на лету, а потом перенести удачную запись в файл.

## Частые грабли

- Пути к файлам — **через прямой слеш и без `public/`**: `/planets/textures/Mars.jpg`.
- Забыл запятую между записями — страница покажет ошибку синтаксиса в консоли (F12).
- Номер узла взят «на глаз» — система встанет не туда; бери номер из карточки узла.
- Хочешь поменять **саму карту** (границы, скорость орбит, свет) — это константы
  в начале `chartMap.js` (`WORLD_R`, `CHART_SPAN`, `BOUNDS`, `ORBIT_SLOW`, `SECTOR`)
  и свет в `main.js` (`AmbientLight`, экспозиция).
