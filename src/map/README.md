# src/map — модули звёздной карты

| Файл | Что делает |
|---|---|
| `main.js` | Точка входа: renderer → мир → риг камеры → интерактор → HUD → поиск/закладки |
| `cameraRig.js` | **Модуль движения и полёта камеры** (заменяет `OrbitControls`) |
| `rigMath.js` | Кадронезависимое демпфирование, углы, форматирование больших чисел и единиц |
| `rigHud.js` / `rigHud.css` | Спидометр, шкала скорости, подсказка управления, тач-джойстик |
| `objectUse.js` | Выбор объекта, карточка, подлёт камеры (теперь через риг), вращение объекта |
| `chartMap.js` | Карта на ТВОИХ ассетах: `need_some_space.glb` (звёздное облако, перекрашено), `nebula_mapa.glb` (1000 узлов + связи), именованные системы, сетка секторов, пикинг, карточки |
| `systems.data.js` | **Твой файл**: системы кампании — привязка к узлам карты, планеты, теги |
| `uiTextures.js` | Процедурные текстуры интерфейса карты (гало, ромбы узлов, подписи) |
| `rng.js` | Детерминированный рандом (карта одинакова у всех игроков) |
| `galaxyMap.legacy.js` | Архив: первоисточник домашней сцены. НЕ подключается; сцена восстановлена через `systems.data.js` (солнце, Плутон, Венера, чёрная дыра на узле карты) |

## Порядок в кадре (важно)

```js
map.update(dt, rig)      // орбиты и LOD — что вообще есть в сцене
interactor.update(dt)    // анимация «старых» объектов (userData.rotationSpeed / orbit)
rig.update(dt)           // камера — уже по актуальным позициям
renderer.render(scene, camera)
```
